## [0.4.0](https://github.com/azabost/clux/compare/v0.3.5...v0.4.0) - 2026-09-21

First release of this fork.

### Changed

- read session state from the `status` field Claude Code maintains in
  `~/.claude/sessions/<pid>.json` instead of inferring it from the last
  `stop_reason` in the conversation transcript
- show one row per pane, letting the pane title decide which conversation the
  row describes; the conversations it hides still contribute their state
- **breaking**: `clux list` prints six tab-separated fields instead of eight

### Added

- `claude session` column carrying the name Claude Code gave the conversation
- bind a daemon-held session to its pane through the pane title, which is the
  only signal that survives when the session has no `TMUX_PANE`, a null `tmux`
  field and a parent chain ending at the daemon
- fold a parked job into the pane it was parked from, pairing them through
  `parkedJobId` and `jobId`
- skip pre-warmed spare sessions

### Fixed

- sanitize every non-alphanumeric character when deriving the transcript
  directory, not just `/`; any working directory containing a dot, including
  every `git worktree` under `.claude/worktrees/`, resolved to a directory that
  does not exist
- locate the transcript by session id when a session changed its working
  directory after starting
- stop overriding idle back to active for a session whose transcript looks stale
  and whose process has children; every session with MCP servers configured has
  children permanently
- publish the release once per tag rather than once per build target, which
  raced and produced two release records for v0.4.0

### Removed

- `mode`, `tasks` and `agents` columns, the `mode` and `mode-rev` sort orders,
  and the `lsof` call that produced the background counts
- release-plz and crates.io publishing; this fork ships through GitHub Releases
- the `next` canary branch and its sync workflow
